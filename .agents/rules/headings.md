# Heading Style Rule

All markdown headings and subheadings (e.g. `##`, `###`, `####`) in this repository should be concise and written primarily in Chinese. Avoid adding long, redundant English translations or subtitles in parentheses (e.g. do NOT use `### 7.2.1 Spring Boot 中的由下而上實踐 (Bottom-Up Practice in Spring Boot)`, instead use `### 7.2.1 Spring Boot 中的由下而上實踐`).
